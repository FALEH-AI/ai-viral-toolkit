# ⚡ AI Viral Toolkit

Free AI-powered toolkit for YouTube Shorts creators.

## Features
- 🎣 **Hook Generator** - Generate 10 viral hooks for 8 niches
- 📝 **Script Writer** - Write complete shorts scripts (15-60 seconds)
- 🏷️ **SEO Optimizer** - Generate titles, descriptions, and tags

## Usage
Open `index.html` in any browser. No server required!

## Tools
All 3 tools work offline (client-side). No API keys needed.
